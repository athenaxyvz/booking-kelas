
# SCRIPT DEMONSTRASI SISTEM BOOKING KELAS


## 1. Pembukaan

Selamat pagi/siang, Bapak/Ibu Dosen.

Kami dari kelompok pengembang akan mendemonstrasikan aplikasi Sistem Booking Kelas.

Aplikasi ini dibuat untuk memudahkan mahasiswa dalam mengajukan peminjaman ruang kelas serta membantu admin mengelola ruang dan memverifikasi pengajuan.

## 2. Demonstrasi Login

1. Jalankan aplikasi.
2. Tampilkan halaman atau menu login.
3. Masukkan akun mahasiswa.
4. Tunjukkan bahwa mahasiswa berhasil masuk ke sistem.
5. Coba login menggunakan password yang salah.
6. Tunjukkan pesan kesalahan yang muncul.

## 3. Demonstrasi Fitur Mahasiswa

1. Masuk sebagai mahasiswa.
2. Tampilkan dashboard mahasiswa.
3. Pilih menu pengajuan peminjaman.
4. Isi tanggal, jam mulai, jam selesai, ruang, dan keperluan.
5. Kirim pengajuan.
6. Tunjukkan bahwa status pengajuan menjadi MENUNGGU.
7. Tampilkan menu status pengajuan.

## 4. Demonstrasi Fitur Admin

1. Logout dari akun mahasiswa.
2. Login menggunakan akun admin.
3. Tampilkan dashboard admin.
4. Jelaskan jumlah total pengajuan, menunggu, disetujui, dan ditolak.
5. Buka menu verifikasi pengajuan.
6. Pilih salah satu pengajuan yang berstatus MENUNGGU.
7. Tunjukkan detail pengajuan.
8. Setujui atau tolak pengajuan.
9. Tunjukkan perubahan status pengajuan.

## 5. Demonstrasi Pengelolaan Ruang

1. Buka menu kelola data ruang.
2. Tampilkan daftar ruang.
3. Demonstrasikan penambahan ruang.
4. Demonstrasikan pengubahan data ruang.
5. Demonstrasikan penghapusan ruang yang tidak memiliki pengajuan.
6. Tunjukkan bahwa ruang yang memiliki pengajuan tidak dapat dihapus.

## 6. Penutup

Demikian demonstrasi aplikasi Sistem Booking Kelas dari kelompok kami.

Melalui aplikasi ini, proses pengajuan peminjaman ruang, pemeriksaan ketersediaan, verifikasi admin, dan pengelolaan data ruang dapat dilakukan melalui satu sistem.

Terima kasih.
